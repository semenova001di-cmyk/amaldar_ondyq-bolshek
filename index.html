Рационал сандарға амалдар қолдану

Бүтін және ондық бөлшек сандармен жұмыс істеу

📌 1-Ереже: Бірдей таңбалы сандарды қосу ($3,2 + 4,5$ және $-3,2 - 4,5$)

Таңбалары бірдей сандарды қосқанда, олардың модульдерін қосып, алдына ортақ таңбаны қоямыз:

  • +3,2 + 4,5 = +7,7
  • -3,2 - 4,5 = -(3,2 + 4,5) = -7,7

📌 2-Ереже: Әртүрлі таңбалы сандарды қосу ($-4,2 + 7,5$ және $4,2 - 7,5$)

Таңбалары әртүрлі сандарды қосқанда, модульдері үлкен саннан кішісін азайтып, алдына модулі үлкен санның таңбасын қоямыз:

  • -4,2 + 7,5 = +(7,5 - 4,2) = +3,3
  • 4,2 - 7,5 = -(7,5 - 4,2) = -3,3

📌 3-Ереже: Таңбалардың түйісуі және жақшаны ашу

Жақшаның алдындағы және ішіндегі таңбалар түйіскенде:

Шпаргалка:
+ (-a) = -a
- (-a) = +a

Мысалдар:

  • -4,5 + (-2,3) = -4,5 - 2,3 = -6,8
  • -4,5 - (-2,3) = -4,5 + 2,3 = -2,2

📌 4-Ереже: Тиімді тәсілмен есептеу (Топтастыру)

Өрнекті жылдам есептеу үшін оң сандарды өз алдына, теріс сандарды өз алдына топтастырып алған ыңғайлы:

Мысал: -4,5 + 2,1 - 5,5

  • Теріс сандарды біріктіреміз: (-4,5 - 5,5) = -10
  • Оң санды қосамыз: -10 + 2,1 = -7,9

📌 5-Ереже: Көбейту және Бөлу кезіндегі таңбалар

Жақшадағы таңбалар ережесі (Көбейту / Бөлу):
(-) $\cdot$ (-) = (+)
(+) $\cdot$ (+) = (+)
(-) $\cdot$ (+) = (-)
(+) $\cdot$ (-) = (-)

Мысалдар:

  • (-0,4) $\cdot$ (-2,5) = +1
  • (-1,2) : (0,3) = -4
